## 📝 VIDEO PRODUCTION TIPS

### Recording Setup
1. **Screen Recording**: Use OBS Studio or Loom
2. **Resolution**: 1920x1080 (1080p)
3. **Frame Rate**: 60fps for smooth animations
4. **Audio**: Use a good microphone (Blue Yeti, Rode NT-USB)
5. **Browser**: Chrome with extensions disabled for clean UI

### Editing Tips
1. **Software**: DaVinci Resolve (free) or Adobe Premiere Pro
2. **Transitions**: Use smooth fades between sections
3. **Annotations**: Add text overlays for key points
4. **Zoom**: Zoom in on important UI elements
5. **Speed**: Speed up transaction confirmations (2x)
6. **Music**: Use subtle background music (Epidemic Sound, Artlist)

### Visual Enhancements
1. **Cursor Highlighting**: Use a cursor highlighter tool
2. **Click Animations**: Show click effects
3. **Progress Indicators**: Add section progress bar
4. **Callouts**: Highlight important text/buttons
5. **Split Screen**: Show code + UI side-by-side for technical sections

### Script Delivery
1. **Pace**: Speak clearly at moderate pace
2. **Enthusiasm**: Show excitement about features
3. **Pauses**: Pause after key points
4. **Emphasis**: Emphasize important words
5. **Natural**: Sound conversational, not robotic
