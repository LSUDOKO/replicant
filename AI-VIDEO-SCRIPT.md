# 🎬 REPLICANT - AI Video Script for Judges (60 seconds)

## 🎨 Visual Style Guide

### Color Palette (Consistent Throughout)
- **Primary**: Violet/Purple (#8b5cf6) - For AI agents and tech elements
- **Secondary**: Black (#000000) - Backgrounds and shadows
- **Accent**: White (#ffffff) - Text and highlights
- **Energy**: Cyan/Blue (#00d4ff) - For data flows and connections

### Character Design
**Main Character: "Rex the Replicant"**
- Cute robot character with round body
- Violet/purple metallic body
- Glowing cyan eyes
- Simple, friendly design (think Wall-E meets BB-8)
- Consistent across all scenes

**Supporting Characters:**
- Mini versions of Rex in different colors (his "children")
- Simple geometric shapes for other elements

## 🎬 Production Workflow

### Step 1: Generate Character Reference
Create Rex's character sheet first:
```
Character sheet of cute robot mascot named Rex, violet/purple metallic body, 
round friendly design, glowing cyan eyes, multiple angles (front, side, back, 3/4), 
multiple expressions (happy, excited, thinking), cartoon 3D style, 
Pixar quality, clean white background, turnaround reference
```

### Step 2: Generate Each Scene
Use the prompts above for each scene, referencing Rex's character sheet

### Step 3: Edit Together
- Use CapCut, Premiere Pro, or DaVinci Resolve
- Add transitions (0.5s crossfades)
- Add text overlays
- Add background music
- Add sound effects
- Color grade for consistency

### Step 4: Add Narration
- Record voiceover (or use ElevenLabs AI voice)
- Sync with visuals
- Mix audio levels

## 💡 Pro Tips

### For Consistency
1. Generate Rex character sheet FIRST
2. Use same prompt structure for all scenes
3. Always mention "violet and cyan color scheme"
4. Keep "cartoon 3D style" in every prompt
5. Use same lighting setup ("dark background, dramatic lighting")

### For Quality
1. Generate at highest resolution available
2. Use "Pixar style" or "Disney style" for quality reference
3. Upscale final renders if needed
4. Color grade in post for consistency

### For Speed
1. Generate all scenes in parallel
2. Use templates for similar scenes
3. Reuse character animations where possible
4. Keep it simple - don't overcomplicate
