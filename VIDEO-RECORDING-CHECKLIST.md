# 🎬 Video Recording Checklist

## 📋 PRE-RECORDING SETUP

### Technical Setup
- [ ] Install OBS Studio or Loom
- [ ] Set resolution to 1920x1080 (1080p)
- [ ] Set frame rate to 60fps
- [ ] Test microphone (Blue Yeti, Rode NT-USB, or similar)
- [ ] Close unnecessary applications
- [ ] Disable browser extensions
- [ ] Clear browser cache
- [ ] Enable cursor highlighting tool
- [ ] Test screen recording (30s test clip)

### Environment Setup
- [ ] Start local development server (`npm run dev`)
- [ ] Connect wallet to 0G Galileo testnet
- [ ] Ensure wallet has testnet tokens
- [ ] Mint at least 2 genesis agents (for demo)
- [ ] Have one agent already evolved (for history demo)
- [ ] List one agent on marketplace (for buy demo)
- [ ] Clear browser console
- [ ] Open Discord channel (for Alpha Hunter demo)

### Script Preparation
- [ ] Print or display script on second monitor
- [ ] Practice narration (aim for natural, conversational tone)
- [ ] Time each section (adjust if needed)
- [ ] Prepare transitions between sections
- [ ] Have backup talking points for each section

## 🎯 TIPS FOR SUCCESS

### Narration Tips
1. **Speak clearly** - Enunciate, don't mumble
2. **Vary your pace** - Speed up for excitement, slow down for important points
3. **Show enthusiasm** - Sound excited about the features
4. **Pause strategically** - Give viewers time to absorb information
5. **Be conversational** - Talk like you're explaining to a friend

### Visual Tips
1. **Keep cursor visible** - Use cursor highlighter
2. **Zoom on important elements** - Make sure viewers can see details
3. **Use smooth transitions** - No jarring cuts
4. **Maintain consistent pacing** - Don't rush or drag
5. **Show, don't just tell** - Demonstrate features in action

### Technical Tips
1. **Test everything first** - Do a full dry run
2. **Have backup plans** - What if transaction fails?
3. **Monitor audio levels** - No clipping or distortion
4. **Check lighting** - Screen should be clearly visible
5. **Save frequently** - Don't lose your work!

### Engagement Tips
1. **Ask questions** - "Have you ever wished your AI could improve itself?"
2. **Use analogies** - "Like Pokemon evolution, but for AI"
3. **Show real value** - "This agent generated 50 signals in 30 days"
4. **Create urgency** - "Try it today on testnet"
5. **Call to action** - "Link in description"
